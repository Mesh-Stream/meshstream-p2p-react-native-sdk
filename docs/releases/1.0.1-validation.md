2026-10-26，当前 Apple Silicon Mac。**本地升级与候选包双端验收通过；用户安排晚间再发布，npm/GitHub 发布均未执行。**

## 版本与 API

- RN 包：`react-native-meshstream@1.0.1`。
- iOS：公共 CocoaPods `MeshStreamKit (= 1.0.4)`。
- Android：公共 Maven `io.meshstream:meshstream-android-sdk:1.0.4`。
- `await MeshStream.getSdkVersion()` 实际返回当前平台已加载的原生版本 `1.0.4`。
- `await MeshStream.getVersion()` 返回 `{packageVersion: '1.0.1', nativeSdkVersion: '1.0.4', platform: 'ios' | 'android'}`。
- 两端均在创建客户端之前调用并验证这两个 API，不需要 Key；原生版本来自原生运行时，非 JS 常量。
